# 🍔 McLife Desk｜麦麦人生工作台

> **记录每一次点麦，也记录你的生活。**

你有没有过这样的时刻？

忙完一天，点开麦当劳准备犒劳自己。订单完成后，你却突然想起：这个月到底吃了几次？花了多少钱？我在麦门信徒里算什么水平？我每次都点一样的，还是其实一直在被某个口味支配？

我们总是在下单，却很少真正看见自己的点餐生活。

于是有了 🍔**McLife Desk 麦麦人生工作台**：一个连接真实订单、记录麦门生活，也帮你重新认识自己的个人工作台。

它有两个最有趣、也最容易让人上头的入口：

### 🪪 订单一同步，自动生成你的「本月麦门档案」

安装并连接麦当劳 MCP 后，无需手动填表，工作台会根据你当月真实订单，自动计算本月的麦门等级、消费次数、金额和行为标签。切换到上个月，你还能看到上个月的自己——每个月都是一份新的麦门档案。

### 🧠 做个趣味测试，看看你是哪种「麦门消费人格」

你是深夜靠汉堡续命的“快乐补给型”？是优惠券研究到极致的“精打细算型”？还是认准固定套餐、从不接受背叛的“专一忠诚型”？通过轻松的趣味测试，找到属于你的麦门消费人格，生成一张可以分享的麦门身份卡。

除此之外，它还会记录你的点餐日历、消费账本、餐品与热量，结合预算、忌口和口味偏好，帮你在下一次“今天吃什么”的时候少一点纠结。

它不劝你戒掉麦当劳，也不替你定义什么是健康生活。它只是想让每一次忙碌后的奖励、每一次深夜里的安慰、每一次和朋友分享的套餐，都留下属于你的生活痕迹。

**记录每一次点麦，也记录你正在经历的人生。**

如果你也想知道自己本月是哪一等级、属于哪种麦门人格，欢迎安装试试。觉得这个工作台有点意思，或者它刚好帮到了你，**欢迎点一下右上角的 ⭐ Star**，让更多人一起看看自己的麦门人生。

## 🌟 这不只是一个点餐助手

很多时候，我们打开麦当劳，不只是因为饿。

可能是加班后给自己的奖励，可能是下雨天不想出门，可能是和朋友分享一份套餐，也可能只是今天想吃一个熟悉的味道。

但当“偶尔一次”变成每周几次，我们很少真正回头看过自己的选择：

- 💸 钱都花在了哪些餐品上？
- 📅 我多久会点一次麦当劳？
- 🔥 最近的热量摄入是否超出自己的预期？
- 🧾 哪些优惠真的帮我省了钱？
- 🪪 我到底属于哪一种麦门信徒？

**McLife Desk** 把这些零散的订单，整理成一个属于你的个人工作台，让每次点餐都能被记录、被理解，也能成为下一次更适合自己的选择参考。

## 🧰 工作台里有什么？

### 📅 麦麦点餐日历

把真实订单按日期沉淀下来。打开日历，就能看到哪一天点过麦、吃了什么、花了多少钱，以及已知的热量信息。

### 📊 麦门账本

按月查看消费次数、金额、优惠使用和订单明细，帮助你看见自己的麦门消费节奏，而不是只在付款后凭感觉猜测。

### 🪪 当月麦门档案等级

系统根据当前月份的真实订单动态计算等级。切换历史月份后，等级也会随月份变化，避免用一次性标签定义长期的你。

### 🧠 麦门消费人格测试

通过轻量、有趣的选择题，发现你更像“深夜续命型”“优惠研究型”还是“固定套餐型”。测试结果是趣味身份表达，不影响真实消费等级。

### 🍟 今日吃什么

结合实时菜单、门店、优惠、预算、忌口、口味偏好和近期订单，给出最多三个有取舍的建议：更省钱、更符合习惯，或尝试一点新口味。

### 🏷️ 个人点餐档案

首次使用时，可以告诉工作台你的常用城市或门店、预算、忌口、饮料偏好和是否记录热量。门店信息仍需通过 MCP 查询确认，避免使用过时信息。


## 🚀 如何开始？

### 1️⃣ 准备自己的 MCP

申请属于自己的麦当劳 MCP Token，并在 WorkBuddy 中配置 MCP Connector.

📖![MCP 使用指南：东亚 MCP Server GitHub 使用指南](https://github.com/M-China/mcd-mcp-server)

### 2️⃣ 安装 Skill

将本项目安装到 WorkBuddy，按照 `INSTALL.md` 完成配置。

### 3️⃣ 初始化工作台

在 WorkBuddy 中输入：

```text
初始化麦麦人生工作台
```

工作台会引导你确认个人偏好，并通过 MCP 查询门店和可用数据。

### 4️⃣ 开始使用

你可以直接说：

```text
同步近期麦当劳订单
打开我的麦麦点餐日历
看看今天吃什么
查看本月麦门账本
开始麦门消费人格测试
生成我的麦门身份卡
```

## 🔌 MCP 在这里做什么？

McLife Desk 不是静态 HTML 看板。工作台中的实时信息来自用户自己的麦当劳 MCP：

- 🏪 查询城市、门店与可用服务
- 🍔 查询菜单、餐品、价格和营养信息
- 🎁 查询优惠与可用活动
- 🧾 查询近期订单并同步到个人工作台
- 🛒 根据用户确认创建订单
- 🔎 查询订单状态，确认支付后再记录为已消费订单

工作台模板只负责展示已经获取并保存的数据；不会伪造订单、价格、库存或支付结果。

## 🔐 隐私与安全

- 每位用户必须使用自己的麦当劳 MCP Token
- 本项目不包含真实 Token、密码、手机号、地址或订单数据
- 不要将真实 Token 提交到 GitHub
- 订单历史同步需要用户明确允许
- 创建订单、取消订单、领券等高风险操作必须经过用户确认
- 热量和营养数据仅供记录与参考，不构成医疗或专业营养建议
