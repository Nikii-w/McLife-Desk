# 麦门身份卡系统（月度等级 + 行为标签 + 消费人格测试）

来源：《麦门认证系统-功能需求》。定位：趣味消费记录功能，**不是麦当劳官方会员等级、官方认证或品牌背书**。禁止使用"官方认证""官方会员等级"等表述，不得鼓励用户为升级而增加消费。

## 一、本月麦门档案等级

- 数据源：仅使用用户授权且 MCP 实际返回的订单（orders.csv 中 `data_source=mcp` 优先；手动补录可计入但需标注）。
- 绑定月份，按月动态计算；切换月份重新计算并展示：等级、标签、订单次数、消费金额、优惠节省、餐品探索数量。
- 数据不完整时必须显示：「本等级基于当前可读取的订单计算，可能不包含全部历史消费。」

### 等级规则（订单次数为主，金额和行为为辅）

| 等级 | 条件 | 描述 |
|---|---|---|
| Lv.1 路过麦香 | 当月 1-2 次有效订单 | 偶尔路过，但每次都知道该吃什么。 |
| Lv.2 快乐回头客 | 当月 3-5 次有效订单 | 你和麦门已经建立了稳定联系。 |
| Lv.3 麦门熟客 | 当月 6-9 次有效订单 | 菜单不用翻太久，你已经有自己的答案。 |
| Lv.4 麦门常驻居民 | 当月 ≥10 次订单，且满足辅助条件至少一项（持续记录 / 餐品探索≥3种 / 优惠使用） | 这里不是你的常去之处，这里更像你的第二个补给站。 |

当月 0 单：不生成等级，如实显示"本月暂无有效订单"。不得用虚构订单或示例数据计算真实等级。

### 月度行为标签（基于当月真实数据，最多 2 个）

- 薅券型选手：当月优惠节省明显或多次用券
- 稳定复购派：同一餐品出现于 ≥40% 订单
- 新品探索家：餐品种类多、去重率高（订单≥3 且去重率≥70%）
- 深夜补给党：订单集中在晚间时段（需要订单时间数据，缺失则不生成）
- 鸡肉忠实拥趸 / 薯条守护者 / 无糖饮料派 / 情绪价值派 / 门店熟客（同一门店≥60%）/ 套餐研究员
- 数据不足时显示：「数据不足，暂不生成标签」

## 二、麦门消费人格测试

- 8 道选择题、每题 4-5 个选项、可跳过、完成后立即出结果、支持重测、新结果覆盖旧结果但保留测试时间、结果不影响月度等级。
- 结果为 6 类人格（由维度得分计算，不由大模型随机生成）：麦门定番派 / 麦门薅券王 / 麦门探索家 / 麦门快乐补给党 / 麦门情绪价值派 / 麦门轻负担派。
- 六个维度：价格敏感度、稳定偏好度、探索倾向、即时满足倾向、情绪价值倾向、饮食记录倾向。每题每个选项映射到一个维度（+1 分），得分最高为主人格，第二高（≥最高分 75%）为副标签。分数接近可混合表达，但不创造第七类人格。
- 完整题目与人格文案见工作区需求文档《麦门认证系统-功能需求.md》；dashboard.html 内置同规则的交互测试（localStorage 持久化，用户可删除）。
- 对话内测试：逐题输出 → 用户逐题回答（或"跳过"）→ 按维度计分 → 输出主人格+副标签+关键词+文案+适合推荐 → 询问是否写入档案。

## 三、麦门身份卡

展示：当前月份、月度等级、行为标签、消费人格（+副标签）、当月点餐次数、消费金额、优惠节省、探索餐品数量、数据完整度、最后更新时间。首页优先展示身份卡。

- 月份切换：等级/标签/统计动态更新；人格结果保持不变（不属于月度统计）。
- 分享版：必须保留「由麦麦人生工作台生成 · 非麦当劳官方认证 · 数据周期：YYYY-MM」；隐藏订单编号、门店地址、配送地址、账号信息。
- 隐私：不把消费数据发送到公开平台；用户可关闭订单同步与等级计算、删除订单记录/测试结果/身份卡数据。
- 验收口径见需求文档第七章（10 条指令测试）。
