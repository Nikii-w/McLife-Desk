# 月度复盘示例（monthly-review.md）

用户：`分析我最近 30 天的麦当劳消费。` / `生成本月麦门报告。`

## 流程

1. 读取 orders.csv + nutrition.csv，确定数据范围（起止日期）
2. 检查 MCP 可用性：可用 → 询问是否顺带同步新订单后再分析；不可用 → 仅基于已保存数据分析，并在报告中声明数据截止时间
3. 计算观察性指标：
   - 最近 7 天 / 30 天点餐次数、本月总消费、平均单次消费
   - 优惠节省金额（discount 字段汇总）
   - 已知或估算热量：每日汇总 + 平均单次（nutrition.csv 的 known/estimated 分开统计）
   - 最常点餐品、餐品重复率
   - 含糖饮料、薯条、甜品出现频率
4. 输出报告（对话内先给摘要）：
   - 按 templates/monthly-report.md 生成 `monthly-reports/{YYYY-MM}.md`
   - 报告必须列出数据范围和缺失情况（缺金额/缺热量的订单数、无同步的日期段）
5. 可选：用 templates/dashboard.html 生成静态辅助视图，只填已保存数据，缺数据处写"—"

## 表述红线

- 只用"已知热量 / 估算热量 / 记录热量"等观察性表述
- 不输出医疗诊断、减肥保证、疾病建议、绝对性结论
- 引用任何指标时能对应到具体数据行，不凭印象编数字
